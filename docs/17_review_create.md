## Структура базы

Для варианта созданы таблицы `categories`, `variants`, `products`, `stock_items`, `roles`, `users`, `orders` и `order_items`.

| Ограничение | Применение |
|---|---|
| PRIMARY KEY | уникальный идентификатор каждой записи |
| FOREIGN KEY | связи категорий, вариантов, товаров, пользователей и заказов |
| NOT NULL | обязательные названия, логины, даты и номера заказов |
| UNIQUE | названия справочников, логины и номера заказов |
| CHECK | положительный объём и цена, неотрицательный остаток, положительное количество заказа |
| DEFAULT | дата создания и статус заказа |

## Проверка ограничений

Попытка записать `quantity = -5` отклонена ограничением CHECK. Попытка записать `order_id = 999`, которого нет в таблице `orders`, отклонена внешним ключом.

## Итог

Все восемь таблиц варианта создаются в правильном порядке. Для каждой таблицы задан первичный ключ, для связей используются внешние ключи, а допустимые значения защищены ограничениями.
