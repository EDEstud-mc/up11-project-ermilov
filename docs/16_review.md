## Анализ предметной области

Информационная система хранит каталог парфюмерии, варианты объёма, остатки, пользователей и заказы.

| Сущность | Назначение |
|---|---|
| categories | категории ароматов |
| variants | варианты объёма флакона |
| products | парфюмерные товары |
| stock_items | остатки и цены вариантов |
| roles | роли пользователей |
| users | учётные записи покупателей и сотрудников |
| orders | заказы покупателей |
| order_items | позиции заказов |

## Основные связи

- categories 1:N products;
- products 1:N stock_items;
- variants 1:N stock_items;
- roles 1:N users;
- users 1:N orders;
- orders 1:N order_items;
- products 1:N order_items;
- variants 1:N order_items.

## Проверка 3НФ

Каждая таблица содержит атомарные значения. Неключевые атрибуты зависят от полного первичного ключа и не зависят друг от друга. Данные категорий, вариантов, ролей и пользователей вынесены в отдельные таблицы, а связи заданы внешними ключами.

Исходная таблица заказов разделена на `clients`, `orders` и `order_items`. Для примера товаров сведения о производителе вынесены в `manufacturers`, а товар хранит `manufacturer_id`.
